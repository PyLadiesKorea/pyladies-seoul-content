## Talks I Really Enjoyed

Two talks really stood out to me. Following along in a foreign language was a bit tough... but most of the speakers shared their GitHub repos, which helped a ton.

### 1. Stop Trusting Your LLM. Start Breaking It. (Cyrus Mante)

![Stop Trusting Your LLM talk](/content-media/stories/20261109-pycon-tw-2026-recap-cyw/tw-07.webp)

This talk was all about AI red-teaming: poking at LLM-powered apps the way an attacker would to find security holes. It walked through automating tests for things like prompt injection, jailbreaks, and data leaks with Python tools such as garak, deepteam, and deepeval.

- GitHub: <https://github.com/mattekudacy/pycon-tw-2026>

### 2. Avoiding Zero-Trade Policies in RL with a Decoupled MLOps Architecture (Sho Tanaka)

![Avoiding Zero-Trade Policies talk](/content-media/stories/20261109-pycon-tw-2026-recap-cyw/tw-08.webp)

This one tackled "Zero-Trade Collapse," where an RL-based trading agent learns that the safest move is to just never trade, and presented an architecture to fix it.

The idea is to let the AI focus only on generating trading signals, and hand off the actual order execution and risk management to a separate rule-based engine. It's directly relevant to the field I work in, so I was all ears. Well, I tried to be.. my English listening didn't quite keep up, so I ended up digging through the code once I got back to Korea.

- GitHub: <https://github.com/tsho/py-execution-engine>

As someone building services in the digital asset space, I walked away with a bunch of ideas I can actually use at work!
