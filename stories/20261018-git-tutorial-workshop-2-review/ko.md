2026년 7월 26일, 신림 관악청년청 4층 세미나실에서 PyLadies Seoul의 두 번째 Git 튜토리얼 워크샵을 열었어요. 운영진 2명과 참가자 2명, 총 4명이 함께한 작은 모임이었어요. Git을 처음 배우거나, 사용하면서도 헷갈렸던 부분을 다시 짚어보고 싶은 분들을 위한 자리였어요.

오후 1시부터 5시까지, 내 컴퓨터에 변경 사항을 기록하고 GitHub에 올린 뒤 Pull Request(PR)로 기여하는 흐름을 따라가도록 프로그램을 준비했어요. `init`, `add`, `commit` 같은 명령어를 직접 써보고, 내 작업을 다른 사람과 나누는 과정까지 연결해 보는 구성이었어요.

그 과정은 실습 저장소에도 남았어요. 한 참여자는 `git init`부터 파일 작성, `git add`, `git commit`, `git log`까지 배운 내용을 적어 PR을 올렸고, 이 PR은 당일 저장소에 병합됐어요. 직접 남긴 기록이 함께 쓰는 저장소의 일부가 된 거예요. [실습 PR 보기](https://github.com/PyLadiesKorea/pyladies-seoul-git-workshop/pull/10)

처음 브랜치를 만들어 자기소개를 올렸다는 PR에는 이런 소감도 담겼어요.

> 친절하고 이해하기 쉽게 알려주셔서 너무 감사해요!

같은 실습 파일의 '나에게 Git이란?'에는 Git과 친해지고 싶다는 마음이 적혀 있었어요. 낯선 도구를 직접 써보고, 더 배워보고 싶은 마음을 남겨주셨다는 점이 반가웠어요. [소감이 담긴 PR 보기](https://github.com/PyLadiesKorea/pyladies-seoul-git-workshop/pull/8/files)

행사 당일 저녁에 받은 익명 설문에는 한 분이 응답해 주셨어요. 만족도는 5점 만점에 5점이었고, 좋았던 점으로는 이렇게 적어주셨어요.

> 소규모로 대화하고 쉽게 질문하고 따라할 수 있어 좋았습니다.

보완할 점도 있었어요. 같은 응답에는 자료가 간소해서 현장에서 이해하기 위해 질문이 필요했다는 의견이 담겼어요. 질문하기 편한 분위기와 함께, 설명을 충분히 담은 자료도 필요하다는 점을 돌아보게 됐어요.

다음 날 운영 회의에서는 오프닝과 진행, 장소에 대한 긍정적인 평가가 있었어요. 홍보를 조금 더 일찍 시작했으면 좋았겠다는 의견과, 다음 회차를 준비한다면 리눅스와 vim 명령어 관련 질문도 미리 정리해 두자는 제안도 남겼어요.

함께 실습하고 소감을 남겨주신 모든 분께 감사드려요. 이번에 해본 작은 실습이 다음 커밋과 PR을 시도할 때 도움이 되었으면 좋겠어요. 다음 모임에서도 함께 배우고, 직접 해보는 시간을 이어가고 싶어요.
