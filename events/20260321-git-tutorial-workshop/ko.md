**PyLadies Seoul: 깃 튜토리얼 워크샵**
**파이레이디스 서울이 세계 여성의 날을 축하합니다!**

[Git이 아직 어렵게만 느껴진다면?]
세계 여성의 날이 있는 3월을 맞아, 소규모 집중 Git 워크샵을 진행합니다. 오프라인 환경에서 차근차근 실습하며 익혀나갈 예정입니다. Git 사용법부터 오픈소스 기여까지 나아갈 수 있도록 도와드립니다! Git을 한 번도 써본 적이 없거나, 써봤지만 아직 헷갈리는 여성 누구나 환영합니다.

**행사 안내**

* 일시: **2026\. 03\. 21 \(토\) 14:00 – 17:00**
* 장소: 신림 관악청년청 4층 세미나실
* 주소: 서울 관악구 남부순환로 1759
* 인원: 선착순 3명
* 대상: Git에 관심 있는 여성 누구나
* 참가비: 무료

**타임라인**

* 14:00 – 14:50 \| 1부: 내 컴퓨터에 기록 남기기
* 15:00 – 15:50 \| 2부: GitHub에 내 코드 올리기
* 15:50 – 17:00 \| 3부: 오픈소스 기여 맛보기 \(PR\)

**이런 분들께 추천해요**

* Git이 처음이거나 기초부터 다시 잡고 싶은 분
* commit, push, pull 용어가 아직 낯선 분
* 협업 툴로 Git을 제대로 활용해보고 싶은 분

**다룰 내용**

* Git의 개념과 필요성 이해
* 기본 명령어(init, add, commit, push, pull) 실습
* GitHub 연동 및 Pull Request(PR) 체험

**사전 준비**
개인 노트북을 꼭 가져와주세요!
워크샵 전 아래 사항을 미리 완료 부탁드립니다.

1. GitHub 계정 생성: github.com
2. IDE 설치: VS Code 등 본인이 편한 에디터
