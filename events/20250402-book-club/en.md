"Everything a Data Analyst Needs to Know About Software Engineering"
Have you been so focused on statistics and modeling that you've struggled to pay attention to code quality and maintainability? Now, learn the essential software engineering knowledge for data scientists through familiar Python examples!

* Learn real-world tips to improve scalability and maintainability of data analysis projects
* Enhance your software engineering skills necessary for collaboration with developers
