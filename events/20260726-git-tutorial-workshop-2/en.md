**[PyLadies Seoul] Git Tutorial Workshop (2nd Edition)**

**[Still find Git difficult?]**
Thanks to the wonderful support from our first workshop, we are back with the 2nd edition of our small-group, intensive Git workshop! We will practice step-by-step in an offline environment. We will guide you carefully from the basics of using Git to making your first open-source contribution! We welcome any woman who has never used Git before, or has tried it but still finds it confusing.

**📌 Event Details**

* **Date & Time:** July 26, 2026 (Sun) 13:00 – 17:00
* **Location:** Seminar Room (4th Floor), Gwanak Youth Center, Sillim
* **Address:** 1759 Nambusunhwan-ro, Gwanak-gu, Seoul
* **Capacity:** 8 people (First-come, first-served)
* **Target Audience:** Any woman interested in Git
* **Fee:** Free

**⏰ Timeline**

* 13:00 – 14:00 \| Part 1: Saving records on my computer
* 14:10 – 15:10 \| Part 2: Uploading my code to GitHub
* 15:20 – 16:30 \| Part 3: A taste of open\-source contribution \(PR\)
* 16:30 – 17:00 \| Part 4: Q&A and Networking

**🙋‍♀️ Recommended for**

* Those who are new to Git or want to rebuild their foundation from scratch
* Those who are still unfamiliar with terms like commit, push, and pull
* Those who want to properly utilize Git as a collaboration tool

**💻 What we will cover**

* Understanding the concept and necessity of Git
* Practicing basic commands (init, add, commit, push, pull)
* GitHub integration and Pull Request (PR) experience

**✅ Prerequisites**

* Please make sure to bring your personal laptop!
* Please complete the following before the workshop:
* Create a GitHub account: [github.com](https://github.com)
* Install an IDE: VS Code or any editor you are comfortable with
