7월 26일, 관악청년청에서 두 번째 Git 튜토리얼 워크숍을 진행했어요. 내 컴퓨터에 변경 사항을 기록하는 것부터 GitHub에 코드를 올리고 Pull Request(PR)를 보내는 것까지, 차근차근 실습하는 시간이었습니다.

이번 워크숍에서는 Git 기본 명령어와 GitHub 연동을 익히고, 실습 저장소에서 PR을 작성하고 병합하는 과정도 함께했어요. 코드에 남긴 작은 변경 사항을 다른 사람과 나누는 경험이 오픈소스 기여의 첫걸음이 되길 바랍니다.

함께 실습하고 질문을 나눠 주신 분들께 감사드려요!
