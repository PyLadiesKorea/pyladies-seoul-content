**DuckDB 실전 활용 - 바이브 코딩을 활용한 대규모 유튜브 데이터 수집부터 분석까지**
**With 박조은**

**<소개>**
DuckDB는 "SQLite for Analytics"라 불리는
초고속 분석 데이터베이스입니다.
이번 밋업에서는 실제 유튜브 데이터를 수집하고,
DuckDB를 활용해 데이터 분석까지 이어가는 실습 중심의 세션을 진행합니다.
데이터 분석을 처음 접하는 분부터, SQL 기반의 워크플로우를
더 효율적으로 만들고 싶은 분들까지 환영합니다.
모든 여성분들을 환영합니다!
