# ✨ OpenAl API를 활용한 데이터 수집 및 대량의 문서처리 ✨

안녕하세요! 이번 프로그램은 지난 번 조은 님께서 발표해 주신 세미나에 이어서 이번에는 새로운 주제로 OpenAI API와 LangChain 같은 AI 도구들을 활용하여 Python을 통해 데이터 수집과 번역을 실습해보는 시간을 가질 예정입니다.

* **본 행사에는 여성만 참여 가능합니다!**

**워크샵 개요**

* **일시:** 2024년 11월 23일 토요일 오후 12시 30분~4시 30분
* **장소:** 한국고등교육재단 3층 위시켓 (장소 후원: 위시켓)
* ***주의사항: 워크숍 장소에 고양이가 있습니다. 알러지가 있거나 고양이를 무서워하시는 분들은 꼭 유의바랍니다.***
* **준비물**
* 파이썬이 설치된 노트북(파이썬이 설치되지 않았다면 Google Colab 으로도 가능)
* ChatGPT, Claude, Perplexity 등의 계정
* ChatGPT API 키
* **참가 인원:** 30명 (선착순 마감)
* **참가 대상**: 여성 누구나
* **참가비**: 2만 5천원 (토스뱅크 1001-0090-0506 윤수진)
* 참가비를 입금하기 어려운 상황이라면 따로 연락바랍니다. (seoul@pyladies.com)

**1. 오프닝 (12:20 PM - 12:30 PM)**
* PyLadies Seoul에 대한 간단한 소개 및 CoC 공유

**2. 세션 1: PyConUS 2023 키노트 자막 가져오기**
* PyConUS 2023 귀도 반 로섬의 키노트 영상 자막을 생성형 AI 프롬프트 작성을 통해 코드를 생성하여 가져오기

**3. 세션 2: OpenAI API 활용 번역 하기**
* 가져온 자막 텍스트를 청크로 나누어 OpenAI API 로 번역 진행
* 번역 결과물은 SQLite로 관리

**4. 세션 3: LangChain 활용 번역 하기**
* LangChain을 사용해서 번역 진행
* 기존 방법과 비교하기

**5. 세션 4: PDF 문서 업로드 및 번역**
* PDF 문서 업로드 및 번역 실습

생성형 AI와 Python에 관심이 많은 분들, API를 활용한 데이터 수집과 번역 실습을 통해 경험을 쌓고 싶으신 분들을 환영합니다. 많은 참여와 관심 부탁드립니다!
