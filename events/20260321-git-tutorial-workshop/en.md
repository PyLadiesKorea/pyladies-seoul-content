**PyLadies Seoul: Git Tutorial Workshop**
**Happy International Women's Day!**

[Does Git still feel intimidating?]
In celebration of International Women's Day this March, we are hosting a small, focused Git workshop. We will learn step-by-step through hands-on practice in an intimate offline setting. We are here to help you navigate everything from basic Git usage to making your first open-source contribution! Any woman who has never used Git or still finds it confusing is more than welcome to join us.

**Event Info**

* Date: 2026. 03. 21 (Sat) 14:00 – 17:00
* Location: Gwanak Youth Center 4F, Seminar Room (Sillim)
* Address: 1759 Nambusunhwan-ro, Gwanak-gu, Seoul
* Capacity: 3 participants (First-come, first-served)
* Eligibility: Any woman interested in Git
* Fee: Free

**Timeline**

* 14:00 – 14:50 \| Part 1: Keeping records on my computer
* 15:00 – 15:50 \| Part 2: Uploading my code to GitHub
* 15:50 – 17:00 \| Part 3: A taste of Open Source contribution \(PR\)

**Recommended for**

* Anyone who wants to learn Git from scratch or rebuild their foundations
* Those who are still unfamiliar with terms like commit, push, and pull
* Anyone who wants to properly utilize Git as a collaboration tool

**What We Cover**

* Understanding the concept and necessity of Git
* Hands-on practice with basic commands (init, add, commit, push, pull)
* GitHub integration and Pull Request (PR) experience

**Prerequisites - Required!**
Please make sure to bring your personal laptop! Please complete the following before the workshop:

1. GitHub Account Creation: github.com
2. IDE Installation: VS Code or any editor you are comfortable with

**Directions**

* Subway: Line 2, Bongcheon Station, Exit 6 (5-minute walk)
* Bus: Get off at 'KT Gwanak Branch' stop (651, 6515, 8541, etc.)
