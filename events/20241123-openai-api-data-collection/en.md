**✨ Data Collection and Large-Scale Document Processing using OpenAI API ✨**

Hello! In continuation of Joeun's previous seminar, this time we are planning a new session where we will practice data collection and translation using AI tools like OpenAI API and LangChain through Python.

* Location: Korea Foundation for Advanced Studies, 3rd Floor, 211 Teheran-ro, Gangnam-gu, Seoul (Venue sponsored by Wishket)

* A laptop with Python installed (Google Colab is also an option if you don't have Python)
* Accounts for ChatGPT, Claude, Perplexity, or similar AI tools
* ChatGPT API Key
* Participants: Limited to 30 people (first-come, first-served)

* 1. Opening (12:20 PM - 12:30 PM): Brief introduction to PyLadies Seoul and sharing of Code of Conduct
* 2. Session 1: Retrieving PyConUS 2023 Keynote Subtitles — Generating and retrieving subtitle code using generative AI prompts from Guido van Rossum's keynote video
* 3. Session 2: Translating with OpenAI API — Translating retrieved subtitle text by splitting it into chunks and using OpenAI API. Managing translation results with SQLite.
* 4. Session 3: Translating with LangChain — Translating using LangChain and comparing with previous methods
* 5. Session 4: Uploading and Translating PDF Documents
* We welcome those who are interested in generative AI and Python, and anyone who wants to gain hands-on experience with data collection and translation using APIs.
