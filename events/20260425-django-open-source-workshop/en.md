"I've always wanted to try open source contribution someday..."
"The codebase is so huge, I have no idea where to even start."
"Communicating in English is so scary!"

If hesitations like these have been holding you back, PyLadies Seoul's Django Open Source Contribution Workshop is exactly the place for you!

This workshop aims to give you a light, friendly first step into the Django ecosystem. From reading the official docs (which can feel daunting alone), to finding a ticket that fits you, to even contributing translations — none of it is hard when you do it with PyLadies members.

• Bring: laptop, GitHub account, Python/Django dev environment set up (★Please be sure to enter the email where we'll send setup instructions when you register!★)

[Timeline]

1. 14:30 ~ 15:00 — Arrival and icebreaking
* PyLadies Seoul community intro
* Brief self-introduction (name, intro, today's goal)
* Intro to Django open source

2. 15:00 ~ 15:30 — Mini tutorial
* Skim the Django official contribution docs
* An organizer shares her "Djangonaut" contribution experience

3. 15:30 ~ 17:00 — Focused contribution + retrospective
* Option A: Attempt a "good first issue" ticket
* Option B: Contribute to the Django docs Korean translation (via Transifex)
* Wrap-up: Share what you accomplished today and cheer each other on

[Who should join]
• People who have used Django and want to try contributing to open source
• Junior developers curious about the open source contribution process (Fork, Branch, PR)
• Those who want to help the community through non-technical contributions like translation
• Women developers wanting to connect with peers facing similar concerns
