---
title: From Local Commits to Sharing on GitHub
---

On July 26, we held our second Git Tutorial Workshop at Gwanak Youth Center. We worked step by step from recording changes on our own computers to sharing code on GitHub and opening a pull request.

The workshop covered basic Git commands, connecting to GitHub, and creating and merging a pull request in our practice repository. We hope that sharing a small change with others can be a welcoming first step into open source.

Thank you to everyone who joined us to practice and ask questions!
